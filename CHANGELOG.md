# Changelog

All notable changes to this project are documented here.

## [Unreleased]

### Added

- Added the reusable `heat_cold_spell` API.
- Added daily temperature data preparation and validation.
- Added historical heat-wave and cold-wave classification.
- Added consecutive-day spell detection.
- Added historical summaries and visualization outputs.
- Added MAX/MIN forecasting model comparison.
- Added selected-model refitting and model manifests.
- Added future MAX/MIN forecasting.
- Added forecast-based spell classification.
- Added README and detailed usage documentation.
- Added contribution, citation, license, and PyPI-readiness documentation.

### Known limitations

- Package metadata is not yet finalized.
- Forecast uncertainty intervals are not calibrated.
- MAX and MIN are modeled independently.
- Data and model-artifact redistribution permissions require confirmation.
- No formal accuracy or scientific-validation claim is made.
